## 📌 Overview

Encodes sentences with the `all-mpnet-base-v2` Sentence-Transformer, compares every pair with cosine similarity, and visualises the result as a heatmap, so sentences with the same meaning light up even when the wording differs.

## ✨ Features

- Sentence embeddings with `sentence-transformers`
- Pairwise cosine-similarity matrix
- Seaborn heatmap of the similarity scores
